把银月公会装进手机

通路一 · 零安装部署 + 添加到主屏幕 = 手机 App
10 分钟总耗时
0 元全部免费
0 安装不用装软件
双平台iPhone / 安卓

开始前：两个必须知道的前提

① 手机上必须能用浏览器打开 https 网址。免费静态托管（Vercel / GitHub Pages）给的都是 https，条件天然满足；如果你自己用 http 搭服务器，iPhone 无法安装到主屏幕。
② 微信里打不开「添加到主屏幕」。iPhone 只能用 Safari，安卓只能用 Chrome。微信里点开链接后，务必点右上角 「···」→「在 Safari 中打开」（安卓是「在浏览器打开」），这是小白卡住的第一名原因。

第一步：把代码存到 GitHub（一次性）

1电脑浏览器打开 github.com，注册并登录（邮箱验证要做完）。

2右上角 + → New repository。

3Repository name 填 silvermoon（只能英文、数字、横杠），下面选 Public，不要勾 "Add a README"。

4点绿色 Create repository。

5在跳转页找到 uploading an existing file（或 "choose your files"），把压缩包里 www 文件夹内的全部文件拖进去。

6拖完后拉到底，点 Commit changes。

没电脑只有手机？GitHub 移动端网页也能上传，但一次只能选一个文件，比较累。建议借台电脑，5 分钟搞定。

第二步：部署上线（30 秒，点三下）

1打开 vercel.com，点 Continue with GitHub 登录并授权。

2点 Add New → Project。

3在 Import Git Repository 列表里找到刚才的 silvermoon，点 Import。

4Configure Project 页面：什么都不用改，直接点 Deploy。

5等约 40 秒，出现 Congratulations! 和一个 Visit 按钮。

6点 Visit，网址形如 https://silvermoon.vercel.app —— 复制它，这就是你的 App 地址。

部署失败 99% 是因为根目录没放对。Vercel 默认认 index.html 在仓库根目录；如果报 "No Framework Detected"，把 Framework Preset 改成 Other 再 Deploy 一次。

第三步：iPhone 装到桌面（Safari）

1打开手机 Safari（苹果自带，别用微信、QQ、Chrome）。

2地址栏输入刚才复制的 https://silvermoon.vercel.app，回车。

3等页面完全加载出来（看到深紫色公会界面）。

4点底部 分享按钮⬆（方框带向上箭头，在地址栏下方一行）。

5在弹出的面板里 往下滑，找到 「添加到主屏幕」（Add to Home Screen）。

6名称默认 银月公会，可改成你想要的名字，点右上角 添加。

7回到手机桌面 ✅ 多了一个公会图标，点开就是全屏 App，没有地址栏。

找不到「添加到主屏幕」？按这个顺序排查：① 用的是不是 Safari（最常见）② 网址是不是 https（http 会藏起来这个选项）③ 页面有没有完全加载完（加载到一半滑不出来）④ 系统是不是 iOS 16 以上（更低版本路径相同，只是图标样式旧）。

第四步：安卓装到桌面（Chrome）

1打开手机 Chrome（别用微信、夸克、手机自带浏览器）。

2地址栏输入 https://silvermoon.vercel.app 回车，等页面加载完。

3出现两种情况，任一即可：

  · 地址栏右侧弹出 「安装」小图标（一个手机带向下箭头）→ 点它 → 点 安装。

  · 没弹图标 → 点右上角 ⋮ 菜单 → 找 「安装应用」或「添加到主屏幕」。

4确认后桌面出现图标，点开即全屏。

Chrome 没弹出安装提示？清掉地址栏的 # 后面的内容（只留纯网址），刷新一次再试；或者升级 Chrome 到最新版。

第五步：验证装对了没有

✅ 正常桌面图标点开 → 全屏、无地址栏、底部有五个 Tab
❌ 没装上点开还是浏览器页面、顶部有地址栏

装好后试三件事：下拉刷新委托板、右滑返回、登录后承接一件委托看信箱是否收到信函。断网再打开，历史页面仍能看（Service Worker 离线壳生效）。

常用问题

点开图标白屏删掉重装一次；多半是部署时文件没传全，回 GitHub 确认 index.html / sw.js / manifest.json 都在
数据好像丢了换了浏览器或清了缓存会丢；演示数据存在浏览器本地，换设备不共享
想换网址Vercel 项目 Settings → Domains，可绑自己的域名
想接真后端把前端 BASE 改成你的服务器地址，然后按《部署指南》里的后端部分起服务
想真机原生包看《iOS部署指南》和《Android部署指南》，需要 Mac / Android Studio

更新网站内容后

改完代码 → 在 GitHub 对应文件点 Edit 修改 → Commit。Vercel 会自动重新部署，用户手机端下次打开自动更新，不用重新添加到桌面。
